# Code of Conduct

This project is part of Eclipse XFSC and adopts the
**Eclipse Foundation Community Code of Conduct** in full:

- <https://www.eclipse.org/org/documents/Community_Code_of_Conduct.php>

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment,
discrimination and personal attacks are not tolerated in any project space — issues, pull requests,
mailing lists or events.

## Reporting

Report unacceptable behaviour to the Eclipse Foundation at <codeofconduct@eclipse-foundation.org>.
Reports are handled confidentially.
